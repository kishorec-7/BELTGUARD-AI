# BELTGUARD AI

**Intelligent Conveyor Belt Joint Health Monitoring & Predictive Protection System**

- **Team:** Spark Spectrum
- **Event:** Smart India Hackathon 2026
- **Problem Statement ID:** SIH26008
- **Theme:** Smart Automation

## Project Overview
BELTGUARD AI aims to detect conveyor-belt joint damage using AI-based image inspection and sensor monitoring. The system combines visual inspection with vibration, temperature, sound, load and tension measurements to assess belt-joint health and support early warnings.

## Proposed Technology
- Raspberry Pi 4 and ESP32
- Computer vision and AI image classification
- Industrial sensors
- PLC, VFD and relay-based control concepts
- Monitoring dashboard
