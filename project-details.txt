PROJECT SUMMARY
BELTGUARD AI is a proposed intelligent monitoring and predictive-protection system for conveyor-belt joints in the iron-ore mining industry. It aims to detect visible cracks, tears and separations and combine image inspection with sensor readings to assess joint condition.

PROBLEM
Conveyor-belt joints face heavy loads, continuous vibration, belt tension, abrasive ore and dusty operating conditions. Damage can develop between manual inspections and may cause material spillage, unexpected failures and downtime.

PROPOSED WORKFLOW
1. Capture belt-joint images using a camera.
2. Process images using computer vision and an AI image-classification model.
3. Collect available sensor and operating data.
4. Combine image and sensor information to calculate an indicative belt-joint health score.
5. Classify the condition into risk levels and display the result on a dashboard.
6. Alert an operator so that inspection or maintenance can be planned.
7. Use motor stop/speed control only where the control hardware and safety logic have been implemented and tested.

TECHNOLOGIES DESCRIBED IN THE PRESENTATION
- Raspberry Pi 4 for edge processing
- ESP32-S3 / ESP32-based sensor interface
- Camera, OpenCV and CNN-based image classification
- Vibration, temperature, sound, load and tension measurements
- PLC, VFD and relay-based motor-control concepts
- Modbus communication where supported by the equipment
